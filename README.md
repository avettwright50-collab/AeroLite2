# AeroLite Browser

AeroLite Browser is a lightweight, minimalist desktop web browser built with Python, PyQt5, and Qt WebEngine. It focuses on a clean interface, fast navigation, and a distraction-free browsing experience.

## Features

- Tabbed browsing
- Custom new-tab page with:
  - Live clock and date
  - Search box
  - Quick shortcuts (YouTube, GitHub, Reddit, Google, X)
- Address bar with URL/search support
- Back, forward, reload, and home navigation
- Bookmark management
- Browsing history viewer
- Download manager
- Security indicator (HTTP/HTTPS status)
- Developer Tools support
- Focus mode for distraction-free browsing
- Zoom controls
- Print current page to PDF
- Multiple browser windows

## Technology Stack

- Python 3.11
- PyQt5
- Qt WebEngine

## Search Behavior

The address bar accepts either:

- Full URLs (example.com)
- Search queries

If the entered text is not recognized as a URL, AeroLite performs a Google search.

## Downloads

Downloaded files are tracked through the built-in download bar, which displays:

- File name
- Download progress
- Completion status

## Security Indicators

- Secure (HTTPS)
- Not Secure (HTTP)
- Site Information

## Running From Source

Install dependencies:

```bash
pip install PyQt5 PyQtWebEngine
```

Run:

```bash
python aerolite.py
```
